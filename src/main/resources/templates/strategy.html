Overview

The bot trades NIFTY weekly options on the Indian market, running four Camarilla setups against the spot index. Every trade is a premium-selling position — the bot sells out-of-the-money (OTM) calls or puts depending on the directional bias of the setup, profiting from time decay and the underlying staying within an expected range.

Entries are gated by a confirmation + tick trigger model on 5-minute spot bars. Every geometric confirmation arms the tick trigger — the trade fires the moment spot touches the confirmation extreme plus an ATR-scaled buffer. A projected-R:R gate at confirmation time drops candidates whose optimistic entry can never satisfy the R:R floor, freeing the pending slot for a better next-bar candidate.

Risk management is layered: per-trade R:R floor, per-day loss cap with a 50 %-qty retry when a full-size fire would breach the cap, portfolio exposure projection, RSI momentum band, and a daily squareoff time.

Camarilla Pivots

Computed nightly from the previous day's High, Low, and Close. The pivot range k = 1.1 × (H − L) sets the scale of all six trading levels:

(H ÷ L) × C
extreme upside target
H4
C + k/2
breakout level
H3
C + k/4
upper reversal zone
TC
2 × P − BC
CPR upper edge
P
(H + L + C) / 3
central pivot
BC
(H + L) / 2
CPR lower edge
L3
C − k/4
lower reversal zone
L4
C − k/2

L5
(L ÷ H) × C

The L3–H3 band is the "neutral" core; price spending time inside it tends to mean-revert. The H4 / L4 levels mark the structural edges — a sustained break beyond them signals a directional regime change. H5 / L5 are extreme-move targets, reached only on strong-trend days.

The TC / P / BC triple defines the day's Central Pivot Range (CPR). Width = TC − BC and its ratio to P gauge the day's compression; the raw levels themselves are not traded — only H3 / H4 / L3 / L4.

The Four Setups

All setups go SHORT an OTM option. Bullish bets sell PUTs (profit if NIFTY stays above the put's strike); bearish bets sell CALLs (profit if NIFTY stays below the call's strike). The bot picks the OTM leg at session-start and holds the same four symbols all day.

Reversals · L3 / H3

Bullish · Mean-reversion L3_REVERSAL
NIFTY wicks below L3 and recovers back above. Bot sells PE near L3, targets H3. SL = confirmation candle low + buffer.
Bearish · Mean-reversion H3_REVERSAL
NIFTY wicks above H3 and rejects back below. Bot sells CE near H3, targets L3. SL = confirmation candle high + buffer.

Breakouts · H4 / L4

Bullish · Trend continuation H4_BREAKOUT
NIFTY closes above H4, breaking out of the pivot band. Bot sells PE near H4, targets H5. SL = confirmation candle low + buffer.
Bearish · Trend continuation L4_BREAKDOWN
NIFTY closes below L4, breaking down through the floor. Bot sells CE near L4, targets L5. SL = confirmation candle high + buffer.

Two-Candle Entry Model

Every 5-minute bar close on the instrument's spot runs a walk through five gates. A bar must FIRST seed a pending confirmation, then a SUBSEQUENT event (a tick or a bar close) must trigger it before the trade fires. The two-bar gate filters out single-bar noise; a projected-R:R gate at confirmation drops candidates that can't satisfy the R:R floor even at their optimistic entry.

Detect
Confirmation candle — the current bar's geometry matches one of the four setups (wicked through the level AND closed back across it).
Buffer
Target buffer — the target level is pulled IN toward the entry by ATR × camarillaTargetBufferAtrMult (default 0.2). Bullish targets shrink downward; bearish targets shrink upward. Matches the "Camarilla level as magnet" pattern — price frequently reverses just before touching the exact level. Set to 0 to disable.
R:R Gate
Projected R:R — at confirmation, R:R is computed against the OPTIMISTIC entry (confirmHigh + ATR × triggerMult bullish / confirmLow − ATR × triggerMult bearish). Any actual fire lands at an equal-or-worse entry, so this projection is an upper bound. If it fails camarillaMinRRRatio, the pending is not seeded — the next bar gets a fresh chance to seed a better candidate.
Trigger
Tick fire. Every confirmation arms the tick trigger — fires the moment spot touches confirmHigh + (ATR × triggerMult) (bullish) or confirmLow − (ATR × triggerMult) (bearish), checked every fast-tick (~1.5 s). Default trigger multiplier 0.25 (a quarter of one 5-min ATR). Set it to 0 to fire at the exact confirmation extreme with no cushion.
Invalidate
Same-thesis invalidation — if a subsequent bar's close crosses the OPPOSITE extreme of the confirmation (close < confirmLow for bullish; close > confirmHigh for bearish), the pending is dropped.
Opposite-direction swap — if a subsequent bar produces a fresh confirmation whose direction is OPPOSITE the currently-held pending, the old pending is discarded and the new one takes its slot, at any age within the expiry window. Same-direction fresh confirmations are ignored (older pending stays put).
Expire
Age-out — a pending older than MAX_PENDING_BARS bars is dropped without trading. The confirmation went stale; the move it predicted didn't materialize in time.

RSI Momentum Gate

At trigger time, before the SELL order goes out, the bot checks NIFTY RSI(14) against a setup-specific band. The momentum check filters out late-entry breakouts at exhaustion (RSI > 80) and reversals against a strong trend (RSI < 40 for bullish reversals, > 60 for bearish reversals).

H4_BREAKOUT50 < RSI < 70
L4_BREAKDOWN30 < RSI < 50
L3_REVERSAL40 < RSI < 60
H3_REVERSAL40 < RSI < 60

Breakouts require directional momentum WITH the trade (RSI in the 50-70 band for bullish H4 breakouts, 30-50 band for bearish L4 breakdowns — trending but not exhausted). Reversals require neutral momentum (RSI 40-60 — no strong trend in either direction, since a rejection thesis can't hold against a runaway move). The check uses the live LTP-projected RSI at the instant of trigger; the chart visible on the Positions page streams that same value every second via SSE.

The momentum gate can be toggled OFF in Settings → Camarilla pane. When disabled, all setups fire on geometry + trigger alone, regardless of RSI.

Order Flow & Exit Logic

When a trigger fires and all gates pass, the bot places a single SELL order on the pre-resolved OTM option leg for that setup. Position size = lots-per-leg × instrument lot size (NIFTY 65), possibly halved by the portfolio-risk retry when a full-size fire would breach the daily loss cap. No SL or target orders are placed on the option premium directly — both are monitored against the spot futures and the bot exits via a market order when either threshold is crossed.

  • Target — spot reaches the setup's Camarilla target level (H5 for H4_BREAKOUT, L5 for L4_BREAKDOWN, H3 for L3_REVERSAL, L3 for H3_REVERSAL), minus the target buffer (bullish) or plus the buffer (bearish). Position closes with profit; theta + favorable spot move both contribute.
  • Stop loss — spot crosses the confirmation candle's far extreme with an ATR × camarillaDirectionalSlBufferAtrMult cushion (default 0.5 × ATR). Position closes with loss; the spot moved against the thesis.
  • 3-tick SL confirmation — to avoid wick-driven false exits, the SL only fires after 3 consecutive sub-second polls confirm the level is breached.
  • Timed squareoff — at the configured squareoff time (default 15:15 IST), all open positions are flattened regardless of SL/target state.

Risk Management

  • Per-trade R:R floor — every fire computes reward (entry → target) and risk (entry → SL). If R:R < camarillaMinRRRatio (default 2.0), the trade is rejected. The projected-R:R gate at confirmation time uses the same floor against the optimistic entry, dropping doomed candidates before they occupy a pending slot.
  • Portfolio exposure cap — before every fire, the strategy projects the combined exposed risk (existing open positions + this new fire's |entryFut − slFut| × ATM_DELTA × qty) and rejects if it would breach portfolioMaxDailyLoss.
  • 50 % qty retry — when the full-lot fire would breach the portfolio cap, the bot retries once at half lots (rounded to whole lots, min 1). If the halved size still doesn't fit, the trade is skipped. No third try — position size never fragments below half.
  • Realized-loss lockout — if today's closed losses exceed portfolioMaxDailyLoss, the strategy locks out for the rest of the session — no new fires on either instrument.
  • RSI momentum gate — see the RSI Momentum Gate section above. Setup-specific bands rule out late-entry breakouts at exhaustion and reversals against strong trends.
  • Trading window — new entries only fire between configured Trading Start (09:30 IST default) and Trading End (13:30 IST default). Existing positions continue to be managed until squareoff.

Real-Time Monitoring

The bot maintains two persistent Fyers WebSocket connections during market hours: one for market data (NIFTY spot + every subscribed option leg's LTP and OI) and one for order events (entry fills, modifications, cancellations). Sub-second SL/target checks run on every spot tick — no polling latency between a level breach and the exit order going out.

Three browser-side surfaces stream live state via Server-Sent Events: the navbar ticker (NIFTY LTP + ΔPct), the Positions page (per-position LTP + MTM), and the Momentum (RSI) chart (live LTP-projected RSI + last-closed canonical RSI, refreshed ~1 Hz). All persistent state survives mid-day restarts and weekend gaps via JSON disk snapshots.
